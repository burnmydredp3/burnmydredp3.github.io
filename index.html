YouTube分析ツール（個人用）

運営者が自分のYouTubeチャンネルの数字（再生回数・視聴時間・収益などの集計）を読み取り、自分のパソコンで分析するための個人用のツールです。一般の方に向けたサービスではありません。

A personal tool that lets the owner read analytics for the owner's own YouTube channels and analyze them on the owner's own computer. It is not offered to the public.

プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-10-02

1. 取得するデータ

Googleアカウントでの許可を得たうえで、次の読み取り専用の権限だけを使います。

  • YouTube Data API（youtube.readonly）：チャンネルと動画の公開情報・統計
  • YouTube Analytics API（yt-analytics.readonly）：再生回数・視聴時間などの集計
  • YouTube Analytics API（yt-analytics-monetary.readonly）：収益の集計

動画の投稿・編集・削除など、書き込みの操作は行いません。

2. 使い方と保存

  • 取得したデータは、運営者自身のチャンネルの分析にだけ使います。
  • データと認証情報（トークン）は運営者のパソコンにだけ保存し、外部のサーバーには送りません。
  • 第三者への提供・販売・広告への利用はしません。

3. Google API サービスのユーザーデータに関するポリシー

Google APIから受け取った情報の使用と移転は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

4. 許可の取り消しと削除

Googleアカウントの「サードパーティのアクセス」（myaccount.google.com/permissions）から、いつでもこのアプリへの許可を取り消せます。取り消した後は、保存されたトークンは使えなくなり、運営者のパソコンから削除します。

5. お問い合わせ

Googleの同意画面に表示されるサポートメールへご連絡ください。

Summary in English

This app uses read-only YouTube scopes (youtube.readonly, yt-analytics.readonly, yt-analytics-monetary.readonly) only to analyze the owner's own channels. Data and tokens are stored only on the owner's computer, are never sold, shared with third parties, or used for advertising. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: the support email shown on the Google consent screen.
